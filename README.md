# 🌍 Language Translator 

 This is a simple desktop language translator built using Python and Tkinter.
It automatically detects the source language and translates text into a selected target language using Google Translator.

# ✨ Features

Auto-detects source language

Supports many languages

Clean and modern GUI

Translate and clear buttons

Status messages (Translating, Complete, Error)

# 🛠 Requirements

Install the required libraries before running the program:

pip install pillow deep-translator

# How to Run

Make sure you have Python 3 installed

Save the file as translator.py

(Optional) Add an image named translator.png in the same folder

Run the program:

python translator.py

# How It Works

Type text in the left box

Select a target language from the dropdown

Click Translate

The translated text appears on the right

#  Libraries Used

tkinter – GUI interface

Pillow – Image handling

deep-translator – Language translation
